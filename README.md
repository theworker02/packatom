# packatom

Pack list/atom set operations for shell-friendly data wrangling.

**Site:** https://theworker02.github.io/packatom/

## Install / run

```bash
git clone https://github.com/theworker02/packatom.git
cd packatom
node src/cli.js
node --test
```
